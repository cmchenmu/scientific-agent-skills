# 论文实验提取使用说明

## 能力边界

本功能面向已下载或已导入到当前项目本地知识库的 PDF、JATS XML、HTML 和 DOCX 论文。它在用户可访问的全文中定位并展示五类证据：实验流程、材料与设备、数据分析方法、结果和结论。网页一次只显示关键词最相关的五篇不同论文；选择论文后才加载该篇的抽取结果。

抽取结果是可追溯的原文片段，不是对缺失信息的补写。`未在可读取正文中定位到对应证据` 表示系统没有找到，不代表论文没有报告该内容。扫描件 OCR 质量、图表内文字和补充材料均会影响结果。

## 启动

```bash
cd /GIT/scientific-agent-skills/lab-agent
./scripts/start-local.sh
```

打开 `http://127.0.0.1:8000`。使用 `Research Assistant Demo` 或 `PI Demo` 身份可先在“研究方向助手”导入开放获取全文，也可通过本地入库命令加入有授权的论文。学生只能检索其已获授权的资料，不能导入。

## 搜索与下载论文

1. 在“搜索并选择下载论文”输入关键词，点击“搜索可下载论文”。页面显示 Europe PMC 总命中数；每页固定显示最多 20 篇可下载开放全文，并保持在滚动框中。分页栏显示当前页附近的五页，可使用首页、上一页、下一页、末页或“跳转到第 N 页”浏览全部搜索结果。
2. 每篇记录显示标题、作者、期刊、年份、影响因子；点击“显示摘要”才会请求并展开该篇摘要，再次点击可收起。
3. 每篇结果可点击“下载此篇”；也可勾选多篇后点击“下载已选择论文”，或点击“下载当前页全部（最多20篇）”。服务端会去重，并拒绝超过 50 篇的下载请求；搜索和浏览本身没有 50 篇上限。
3. 下载并入库完成后，论文会出现在“论文实验提取”的本地已授权检索结果中。下载需要 `Research Assistant Demo` 或 `PI Demo` 身份；搜索不下载全文，学生也可查看检索目录。

研究方向助手生成的候选检索式可点击“查看可下载论文”，将它带入相同的选择下载流程，而不是自动批量入库。

### 排序与影响因子

目录可按相关性、发表年份（新到旧）或影响因子（高到低）排序。排序作用于当前页结果；切换页面后继续按同一条件排序。JIF 不是 Europe PMC 的开放字段；要显示并排序真实影响因子，请从有权限的 JCR 数据导出创建 JSON，并在启动服务前设置路径：

```bash
export LAB_AGENT_JCR_METRICS_PATH="$PWD/data/jcr-impact-factors.json"
```

文件使用规范化期刊名作为键，值必须包含 `jif` 和该 JIF 对应的 `year`：

```json
{
  "nature medicine": {"jif": 58.7, "year": "2024"}
}
```

未在映射中的期刊显示“未导入 JIF”，并在影响因子排序中排在已知分数之后。不要用引用次数、SJR 或 CiteScore 冒充 JIF。

## 我的论文库

“我的论文库”显示当前身份有权访问的已下载论文，并在固定高度的滚动框内列出标题、来源、入库时间、状态和文件格式。点击“下载原文”会将该篇受授权的原始 XML、PDF、HTML 或 DOCX 下载到浏览器默认下载目录。`Research Assistant Demo` 和 `PI Demo` 可删除项目论文及其无其他引用的本地原文副本；学生只能查看和下载其有权限的论文。

## 实验提取操作

1. 在“论文实验提取”输入关键词，点击“检索前五篇论文”。结果仅来自当前项目、当前身份有读取权限的已下载文献。
2. 点击一篇论文。页面展示五类信息，每个条目前的章节名对应原文定位。
3. 当原文统计分析中识别到受支持的方法，使用“下载分析脚本”和“下载 CSV 模板”。当前支持 Welch 双样本 t 检验准备、单因素 ANOVA 准备和简单线性回归准备。
4. 用真实数据替换 CSV 模板中的 `0.0`，保持 UTF-8 编码、表头和每行一条独立观测的约束。使用 Python 运行，例如：

```bash
python two_group_t_test.py input.csv
```

下载的脚本提供输入检查和描述性输出。它不自动得出显著性结论；运行前需根据论文和实际实验核验独立性、分布、方差、预注册比较以及多重比较处理。

## API

搜索可下载目录：`POST /v1/literature/catalog`，请求体为 `{"query":"mouse hippocampus"}`。下载选择：`POST /v1/literature/selected-import`，请求体为：

```json
{"project_id":"mouse-neuro-demo","pmcids":["PMC12345678","PMC23456789"]}
```

`pmcids` 必须为有效 PMC 编号，去重后为 1 至 50 个；接口只下载该列表，不会按关键词补充其他论文。目录检索传入 `page`（从 1 开始）和 `sort_order`；响应包含总命中 `total`、当前 `papers`、`current_page` 和 `total_pages`。摘要通过 `GET /v1/literature/catalog/{pmcid}/abstract` 在用户展开时单篇获取。

`POST /v1/literature/search` 请求体：

```json
{"project_id":"mouse-neuro-demo","query":"mouse hippocampus"}
```

返回不超过五个 `{document_id,title,score,snippet,section}`。选择后调用：

```text
GET /v1/literature/{document_id}/experiment?project_id=mouse-neuro-demo
```

响应的五个证据数组中，每一项都有 `chunk_id`、`section`、`page` 和 `text`；`automations` 中提供脚本、CSV 模板和输入格式说明。两个端点均需要 `X-User-Id`，并在服务端强制项目和文档 ACL。
