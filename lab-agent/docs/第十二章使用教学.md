# 第十二章使用教学：审批、审计、隐私和成本

本章把“上线后可追责”实现为本地可运行的治理模块。它不保存 access token、密码、完整票据、文档全文或原始 payload；每次请求记录可关联的 digest、角色、项目、工具版本、检索文档、审批、外部 ID、延迟、成本、错误和最终状态。

## 1. 已实现组件

实现文件：[governance.py](../app/services/governance.py)

```text
redact_payload(value)
AuditEvent
GovernanceStore.record_event(event, payload)
GovernanceStore.audit_events(request_id)
GovernanceStore.create_budget(task_id, limits)
GovernanceStore.consume_budget(task_id, usage)
GovernanceStore.put_cache(...)
GovernanceStore.get_cache(...)
```

本地数据保存在：

```text
data/governance/governance.sqlite3
```

该目录应加入 `.gitignore`，不能提交到仓库。生产部署可把同一字段契约映射到第六章 PostgreSQL 的 `audit_events` 和任务预算字段。

## 2. 审计事件字段

`AuditEvent` 至少包含：

| 字段 | 用途 |
| --- | --- |
| `request_id` / `trace_id` | 关联一次请求和跨服务调用链。 |
| `actor_id` / `roles` / `project_id` | 记录谁以什么角色访问哪个项目。 |
| `action` / `tool_name` / `tool_version` | 记录业务动作和工具版本。 |
| `params_digest` | 关联参数而不保存原始敏感参数。 |
| `retrieval_document_ids` | 记录检索涉及的文档 ID。 |
| `approval_decision` / `external_request_id` | 连接审批和外部系统结果。 |
| `latency_ms` / `estimated_cost_cents` | 支持 SLO、成本分析和异常发现。 |
| `error_code` / `final_state` | 说明失败原因和最终状态。 |

示例：

```python
from pathlib import Path
from app.services.governance import AuditEvent, GovernanceStore

store = GovernanceStore(Path("data/governance"))
store.record_event(
    AuditEvent(
        request_id="req-001",
        trace_id="trace-001",
        actor_id="student-demo",
        roles=("student",),
        project_id="mouse-neuro-demo",
        action="knowledge.query",
        tool_name="search_documents",
        tool_version="1.0",
        params_digest="sha256-of-structured-params",
        retrieval_document_ids=("document-1",),
        approval_decision=None,
        external_request_id=None,
        latency_ms=42,
        estimated_cost_cents=1,
        error_code=None,
        final_state="completed",
    ),
    {"question": "组织保存条件", "access_token": "never-store-this", "content": "private text"},
)
```

`record_event` 会递归脱敏：token、password、secret、API key、receipt 等字段变成 `[REDACTED]`；`content`、`full_text`、`raw_payload` 等字段只保存 SHA-256 和长度；超长字符串也只保存 hash/长度。

## 3. 隐私检查

调用治理模块时遵守三条规则：

1. 日志保存 digest，不保存 token、密码和完整请求。
2. 检索日志保存 document ID，不保存全文 chunk。
3. 财务票据、患者数据和敏感实验数据只在受控业务存储中保存，并记录最小必要引用。

可以用下面的测试确认审计记录没有泄漏：

```bash
uv run --no-sync pytest tests/test_governance.py -q
```

生产环境还要由数据保护和安全团队确认保留期、删除策略、跨境传输、备份加密和访问审批。脱敏函数不是合规认证的替代品。

## 4. 预算和成本终止

每个任务创建独立预算：

```python
store.create_budget(
    "task-001",
    max_steps=10,
    max_tokens=10_000,
    max_cost_cents=100,
)
```

每次模型或工具调用前扣减：

```python
if not store.consume_budget("task-001", tokens=850, cost_cents=2):
    # 终止后续调用，读取 budgets.stopped_reason 并审计
    raise RuntimeError("budget exhausted")
```

任一 `max_steps`、`max_tokens` 或 `max_cost_cents` 超限后，任务会记录终止原因；后续调用始终返回 `False`。预算检查必须在模型/外部工具调用之前执行，不能调用完成后才补记账。

成本控制建议：

- 分类、字段提取和路由使用小模型；复杂综合才使用大模型；
- 缓存解析、embedding、文献卡片和 artifact，但缓存必须带 ACL；
- 无依赖的只读任务可并行，写入/审批/同一数据集写操作串行；
- 预算、权限、危险操作、重复状态和无进展都应触发终止并审计。

## 5. 带 ACL 的缓存

缓存不是全局共享字典。写入时绑定用户、项目和角色：

```python
store.put_cache(
    "query:abc",
    user_id="student-demo",
    project_id="mouse-neuro-demo",
    roles=["student"],
    value={"document_ids": ["document-1"]},
    ttl_seconds=300,
)
```

读取时必须同时匹配：

```python
value = store.get_cache(
    "query:abc",
    user_id="student-demo",
    project_id="mouse-neuro-demo",
    roles=["student"],
)
```

其他用户、其他项目或不相交角色得到 `None`。生产缓存（Redis、PostgreSQL 或对象存储）必须复制这一检查，不能只在 Agent 层过滤。

## 6. Agent 调用流程

Agent 不直接写日志、扣预算或读取缓存。服务端工具包装器执行固定顺序：

```text
认证身份
-> 解析服务端角色和项目
-> 校验结构化输入
-> consume_budget（调用前）
-> ACL-first 检索/审批/工具调用
-> redact_payload + record_event
-> 返回脱敏结果
```

工具返回值应包含机器可读状态，例如：

```json
{
  "status": "completed",
  "request_id": "req-001",
  "estimated_cost_cents": 2,
  "audit_event_id": "event-001"
}
```

预算耗尽时返回 `budget_exhausted`，不能让 Agent 自动换模型、扩大预算或无限重试。审计事件的 `payload_redacted` 不能被 Agent 当作原文证据。

## 7. 与第八至第十一章的连接

- 第八章知识问答把检索文档 ID、引用验证结果和 latency 写入审计。
- 第九章工具门禁在调用前记录参数 digest，并把拒绝原因写入 `error_code`。
- 第十章论文工作流为每个 checkpoint 和成本终止事件建立 request/trace 关联。
- 第十一章行政适配器记录审批决定、外部请求 ID、幂等键结果和最终状态，但不写入 token 或票据全文。
