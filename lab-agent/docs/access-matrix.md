# 权限矩阵

| 角色 | SOP 读取 | 分析工具 | 论文库发布 | 报销提交 | 审批 |
|------|----------|----------|------------|----------|------|
| student | 自己项目已生效 | 无 | 无 | 无 | 无 |
| research-assistant | 自己项目已生效 | 服务端白名单中的分析模板 | 无 | 草稿 | 无 |
| pi | 自己项目全部 | 服务端白名单中的分析模板 | 可审批共享 | 草稿 | 论文库审批 |
| finance-approver | 被授予的制度文档 | 无 | 无 | 可审批提交 | 报销审批 |
| admin | 全部 | 全部 | 全部 | 全部 | 全部 |

## 强制规则

- 项目角色来自 `user_roles`，不能信任请求体中的角色字段。`admin` 是唯一的跨项目角色。
- 文档读取同时检查项目归属或对象 ACL；ACL 必须明确为 `read` 或 `admin`。学生和研究助理仅能读取 `effective` 文档，PI 可读取本项目任意状态文档。
- 工具允许列表由服务端按项目加载。学生和财务审批人不能运行分析或写入工具。
- 外部写操作必须处于 `pending_approval`，有足够的非申请人批准且没有拒绝；同一 `idempotency_key` 只能领取一次。数据库的 `tasks.idempotency_key` 唯一约束是跨 worker 的最终防线。
